LLMs have fundamentally changed how we work. We need new tooling that doesn't exist yet, and building software is now so cheap that we can tailor our tools to match exactly how we work.
## We are in uncharted territory
The old ways of working are gone. Many of our assumptions no longer hold, and our tools need to change with them. The exciting part is that no one has the answers yet. We don't even know what the solution looks like! We have to explore to find what works.
## Every idea is within reach
The tools we used were full of inefficiencies that we simply got used to. We don't have to put up with that anymore. With LLMs, there is no good excuse not to have the perfect setup for you.

And it isn't only LLMs. We have amazing platforms to build on. [Pi](https://pi.dev/) is infinitely configurable, [bb](https://getbb.app/) is the UI version of that, [Ultimate](https://github.com/HazAT/ultimate) rebuilds itself, and [Omarchy](https://omarchy.org/) lets you customize your entire OS.
## Adaptability is key
With each new frontier LLM, some tools become obsolete, others become more important, and new ones become possible for the first time. You need to be able to iterate quickly, and owning your tooling makes iteration frictionless.
## It is delightful
My coding agent automatically compiles a trail of what I've done for my weekly reflections. It periodically "dreams" to find inefficiencies in its own way of working. It has a built-in tutor with a live map of everything I'm learning and how it all connects.

Work is so much more fun when you have the right tools for the job!
